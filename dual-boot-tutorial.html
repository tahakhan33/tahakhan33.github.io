Windows/Linux Dual Boot Guide

Updated: July 2026 System Configuration

Configuring a workstation for computational physics often requires the best of both worlds. Dual booting allows you to retain Windows for specialized mechanical design software while harnessing a high-performance Linux environment (such as Ubuntu or Linux Mint) for compiling simulation codes and running scientific tools.

Prerequisites

Hardware Requirements

  • A workstation (laptop/desktop) meeting the minimum requirements for your chosen Linux distribution.
  • Internal or external storage (HDD/SSD) with a minimum of 100 GB of free space.
    Note: Modern cross-section data libraries for nuclear simulations often exceed 40+ GB.
  • A USB flash drive (minimum 8 GB).

Software Requirements

  • Rufus (Bootable media creation utility).
  • ISO file for your preferred Linux distribution (e.g., Ubuntu LTS).

Step 1: Create Bootable Media

  1. Connect your USB drive and launch the downloaded Rufus.exe.
  2. Click SELECT alongside the boot selection option and browse for your downloaded Linux ISO file.
  3. Leave all default options as they are, and click START at the bottom of the interface.
  4. Accept all warning prompts to begin formatting. Warning: This will permanently erase all existing data on the USB drive.
  5. Once the green status bar indicates completion, close Rufus.

Step 2: Allocate Storage Space

Open the Windows Disk Management utility by searching for it in the Start menu. You must allocate dedicated space for the Linux distribution from your existing drives.

  • Option A (External Storage): Simply format your external HDD/SSD so it is prepared for the installer.
  • Option B (Internal Storage): Right-click your desired partition and select Shrink Volume. Cut off at least 100 GB of space. Leave this newly freed space as "Unallocated".

Step 3: Configure BIOS/UEFI Boot Priority

To boot from the USB drive, you must access your motherboard's BIOS/UEFI menu. There are two primary methods:

  • Method 1 (Advanced Startup): Open the Windows Start menu, search for "Advanced startup options", and click the first recommended result. Click "Restart now". Navigate through Troubleshoot > Advanced Options > UEFI Firmware Settings and click Restart.
  • Method 2 (BIOS Key): Perform a standard restart and rapidly tap your motherboard's dedicated BIOS key (e.g., F1, F2, F12, DEL, or ENTER).

Once in the BIOS menu, locate the Boot Order (or Boot Priority) settings. Change the order so your USB drive is the first priority, placing it above the Windows Boot Manager. Save the settings and exit.

Step 4: Linux Installation Process

  1. Upon restarting, the system will load the GRUB menu. Select Try and Install Ubuntu.
  2. When prompted for an Internet connection, connect to your Wi-Fi (wired connections configure automatically). This is necessary for downloading background dependencies.
  3. Select Install Ubuntu, followed by Interactive installation (ignore the other options).
  4. Choose Default selection (or Extended selection if you require additional pre-installed utilities, though this consumes more space).
  5. Check the box to Install third-party software for graphics and Wi-Fi hardware (highly recommended). Note: Installing media format support is optional and generally unnecessary for strict academic/research environments.

Step 5: Disk Partitioning

The partitioning steps depend entirely on the storage hardware you configured in Step 2:

  • External Storage (Manual Installation): Select the manual installation option. Click your external drive (if it does not show as free space, click the - icon to clear it). Click the + icon to create partitions.
    • The system will automatically create an EFI partition.
    • Create a Root directory (/) formatted as ext4, allocating roughly 10% of the total space.
    • Create a Home directory (/home) formatted as ext4 using the remaining space for personal files and data libraries.
  • Internal Storage (Automated): Select Install alongside Windows Boot Manager. The installer will automatically locate the unallocated space you created earlier and configure the dual boot.
  • Internal Storage (Manual): Select manual installation and configure the Root and Home directories within your unallocated space as described above.

Step 6: Finalize Configuration

Proceed through the final setup screens. You will be prompted to set a username and password. For frequent terminal users, a small, concise password is highly recommended to save time when executing repeated sudo commands.

No system encryption is required. Select your timezone, verify your partition summary, and click Install.

Post-Installation Boot Order

Once the installation completes, the interface will prompt you to "Restart now". Remove the USB drive and press Enter. If the GRUB menu appears, the setup is successful. However, if the system bypasses GRUB and boots directly into Windows, you must manually re-enter the BIOS/UEFI settings. Ensure that "Ubuntu" is placed above the "Windows Boot Manager" in the boot priority list. Save and exit to restore access to the GRUB menu.
