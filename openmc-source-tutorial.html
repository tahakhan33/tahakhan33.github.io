How to Build OpenMC from Source

Updated: August 2026 Computational Physics

Building OpenMC directly from its source code is ideal for users who want to modify the C++ core, access the absolute latest repository commits, or optimize the executable for specific hardware architectures. This guide covers the complete build process on a Linux environment.

Note: Terminal Privileges

This tutorial assumes you have a working Linux terminal and basic sudo privileges to install dependencies globally.

Step 1: Install Prerequisites

Before compiling OpenMC, you must ensure your system has the correct compilers and build tools. Open your terminal, update your package list, and install git, cmake, and the build essentials.

sudo apt update && sudo apt upgrade -y
sudo apt install git cmake build-essential g++ libhdf5-dev -y

Step 2: Clone the OpenMC Repository

We will pull the latest source code directly from the official MIT/OpenMC GitHub repository. Navigate to the directory where you want to install it (e.g., your home folder or an /opt directory) and run:

git clone https://github.com/openmc-dev/openmc.git
cd openmc

Step 3: Build and Compile using CMake

OpenMC utilizes CMake to manage the build process. We will create a dedicated build directory to keep the source tree clean.

mkdir build
cd build
cmake ..
make -j4
sudo make install

The -j4 flag tells the compiler to use 4 CPU cores to speed up the build process. You can adjust this number based on your specific hardware capabilities (e.g., -j8 for an 8-core CPU).

Step 4: Configure Environment Variables

Once installed, Linux needs to know where to find the OpenMC executable. Add the installation path to your .bashrc profile.

echo 'export PATH=/usr/local/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

Step 5: Verify the Installation

To ensure OpenMC is correctly installed and accessible system-wide, type the following command in your terminal:

openmc --version

If the compilation and path configuration were successful, the terminal will output the current version of your OpenMC build!
