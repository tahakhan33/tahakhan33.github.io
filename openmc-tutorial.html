How to Install OpenMC via Anaconda

Updated: July 2026 Computational Physics

This guide provides a comprehensive, streamlined methodology for setting up the OpenMC Monte Carlo particle transport code using the Conda package manager. Conda simplifies the installation of Python APIs, nuclear data tools, and the OpenMC executable itself.

Prerequisites

Hardware Requirements

  • A workstation or laptop running a Debian-based Linux distribution (e.g., Ubuntu, Linux Mint) or macOS.

Software Requirements

  • Anaconda Distribution. It is recommended to use the full Anaconda distribution rather than Miniconda, as it contains a more complete suite of data science packages out-of-the-box, ensuring a smoother setup.

Step 1: Download & Install Anaconda

  1. Download the Anaconda installer from the official website. The file will default to your Downloads directory.
  2. Open your terminal and navigate to the Downloads folder:
    • Option 1 (GUI method): Open your file manager, navigate to the Downloads folder, right-click, and select "Open in Terminal".
    • Option 2 (CLI method): Press Ctrl+Alt+T (Linux) or open the Terminal app (macOS). Navigate using the command:
    3. cd ~/Downloads
  3. List the directory contents by typing ls. You will see the Anaconda installer script (e.g., Anaconda3-202X.X-Linux-x86_64.sh) listed in white text.
  4. Make the installer executable by running:
    5. chmod +x your_installer_file_name_goes_here.sh
  5. Verify the change by typing ls again. The filename should now appear in green, indicating it is executable.
  6. Execute the installer script:
    7. ./your_installer_file_name_goes_here.sh

    Follow the on-screen prompts. Type yes when asked to accept terms or initialize Conda. Avoid holding down the Enter key, as you may accidentally skip important prompts.

Terminal Refresh

Once the installation is complete, completely close and reopen your terminal. You should now see (base) prepended to your command prompt, indicating that Conda is active.

Step 2: Configure Conda Channels

OpenMC and its dependencies are hosted on the conda-forge channel. You must add this channel to your Conda configuration and prioritize it to prevent package conflicts.

conda config --add channels conda-forge
conda config --set channel_priority strict

Step 3: Create the OpenMC Environment

It is best practice to create an isolated environment specifically for computational reactor physics work. The command differs slightly depending on your operating system.

  • For Linux Users:
    • conda create --name openmc
  • For macOS Users:
    • conda create --name openmc --platform osx-64

Naming Convention Tip

While you can name the environment anything (like openmc-env), using the simple name openmc is highly recommended to save keystrokes during daily use.

Step 4: Activate & Install Dependencies

Activate your newly created environment. Notice how the prefix in your terminal changes from (base) to (openmc).

conda activate openmc

With the environment active, install the OpenMC suite alongside Jupyter Lab for interactive Python notebook development. Conda will resolve and display a list of all required packages.

conda install openmc jupyterlab

Type y and press Enter to confirm the installation. Conda will now download and install OpenMC, the Python API, and Jupyter Lab into your isolated environment.

Step 5: Launch Jupyter Lab

Once the installation finishes, you are ready to begin writing simulation scripts and analyzing cross-sections. Start the Jupyter interface by running:

jupyter lab

This will automatically open a new tab in your default web browser where you can create your first Python notebook and import OpenMC!
