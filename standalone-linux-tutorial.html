Standalone Linux Setup (Ubuntu/Debian)

Updated: August 2026 System Configuration

For dedicated computational physics workstations, a standalone Linux installation (wiping Windows entirely) provides maximum performance and stability, and completely avoids bootloader conflicts. This guide covers a clean installation of Debian-based systems like Ubuntu or Linux Mint.

Prerequisites

Hardware Requirements

  • A workstation or laptop with an internal or external drive (HDD/SSD) that you are prepared to completely erase.
  • A USB flash drive (minimum 8 GB).

Software Requirements

  • Ubuntu LTS ISO or your preferred Debian-based ISO.
  • Rufus for creating the bootable installation media.

Step 1: Create the Bootable USB

  1. Connect your USB drive and launch the Rufus.exe utility on a working computer.
  2. Click SELECT and browse for your downloaded Linux ISO file.
  3. Ensure the partition scheme is set to GPT and the target system is UEFI (non CSM).
  4. Click START at the bottom of the interface. Accept the warning prompts to format the drive. Note: This will erase all data currently on the USB.

Step 2: Configure BIOS/UEFI Settings

To boot from the USB drive instead of your internal hard drive, you must modify your system's boot priority.

  1. Restart your target computer and rapidly tap your motherboard's BIOS key (commonly F2, F12, DEL, or ENTER).
  2. Navigate to the Security menu and disable Secure Boot.
  3. Navigate to the Boot menu and adjust the Boot Order so your USB drive is the primary boot device (Position 1).
  4. Save the settings and exit the BIOS. The computer will reboot directly into the Linux installer.

Step 3: The Installation Process

The installation steps diverge slightly here based on your chosen distribution. Follow the respective path below:

Option A: Ubuntu Setup

Once the GRUB menu appears, select "Try or Install Ubuntu". Follow the initial setup screens to select your language, keyboard layout, and Wi-Fi connection.

Crucial Step: Erase Disk (Ubuntu)

When you reach the "Installation Type" screen, select "Erase disk and install Ubuntu". The installer will automatically format the entire drive, configure the EFI partition, and allocate the rest for your Root (/) filesystem. This eliminates the need for manual partitioning!

Option B: Debian Setup

Once the GRUB menu appears, select "Graphical install". Proceed through the localization screens (language, location, keyboard layout).

During the network configuration phase, Debian will prompt you for two specific identifiers:

  • Hostname: This is your computer's name on the network. You can name it anything you like (e.g., physics-node, workstation, or simply debian).
  • Domain Name: For a standalone personal or home network setup, you should leave this completely blank and click Continue. (If your network requires it, you can safely use local).

Crucial Step: Partition Disks (Debian)

When you reach the "Partition disks" screen, select "Guided - use entire disk". Select your target drive, and then choose "All files in one partition (recommended for new users)". Select "Finish partitioning and write changes to disk" to proceed.

Continue through the final prompts for either distribution. When setting up your user profile, use a short and simple password, as you will need to type it frequently when executing sudo commands for your computational packages.
