Standalone Linux Setup (Ubuntu/Debian)

Updated: August 2026 System Configuration

For dedicated computational physics workstations, a standalone Linux installation (wiping Windows entirely) provides maximum performance and stability, and completely avoids bootloader conflicts. This guide covers a clean installation of Debian-based systems like Ubuntu or Linux Mint.

Prerequisites

Hardware Requirements

  • A workstation or laptop with an internal or external drive (HDD/SSD) that you are prepared to completely erase.
  • A USB flash drive (minimum 8 GB).

Software Requirements

  • Ubuntu LTS ISO or your preferred Debian-based ISO.
  • Rufus for creating the bootable installation media.

Step 1: Create the Bootable USB

  1. Connect your USB drive and launch the Rufus.exe utility on a working computer.
  2. Click SELECT and browse for your downloaded Linux ISO file.
  3. Ensure the partition scheme is set to GPT and the target system is UEFI (non CSM).
  4. Click START at the bottom of the interface. Accept the warning prompts to format the drive. Note: This will erase all data currently on the USB.

Step 2: Configure BIOS/UEFI Settings

To boot from the USB drive instead of your internal hard drive, you must modify your system's boot priority.

  1. Restart your target computer and rapidly tap your motherboard's BIOS key (commonly F2, F12, DEL, or ENTER).
  2. Navigate to the Security menu and disable Secure Boot.
  3. Navigate to the Boot menu and adjust the Boot Order so your USB drive is the primary boot device (Position 1).
  4. Save the settings and exit the BIOS. The computer will reboot directly into the Linux installer.

Step 3: The Detailed Installation Process

The setup process diverges here based on your chosen distribution. Follow the exact step-by-step path for your selected ISO below.

Option A: Ubuntu Setup

  1. Boot Menu: Select "Try or Install Ubuntu" from the initial GRUB boot screen.
  2. Welcome Screen: Choose your preferred language on the left sidebar and click Install Ubuntu.
  3. Keyboard Layout: Select your standard keyboard layout (e.g., English (US)) and click Continue.
  4. Network Connection: Connect to your Wi-Fi network (wired connections are detected automatically). This is necessary to download updates during the setup.
  5. Updates & Software: Select "Normal installation". It is highly recommended to check both "Download updates while installing Ubuntu" and "Install third-party software for graphics and Wi-Fi hardware".
  6. Installation Type: Select "Erase disk and install Ubuntu". Click Install Now, and when the warning prompt appears, click Continue to write the changes to the disk. (This handles all partitioning automatically).
  7. Timezone: Click your location on the map to set your timezone.
  8. User Details: Enter your name, a computer name (e.g., physics-node), a username, and a password. Tip: Use a short password, as you will type it frequently in the terminal!
  9. Completion: Wait for the installation to finish. Click Restart Now, remove the USB drive when prompted, and press Enter.

Option B: Debian Setup

  1. Boot Menu: Select "Graphical install" from the initial GRUB boot screen.
  2. Localization: Over the first three screens, select your Language, Location (Country), and Keyboard Layout.
  3. Network Configuration: Enter a Hostname (e.g., workstation). When prompted for a Domain name, leave the text box completely blank and click Continue.
  4. Root Password setup:

    Sudo User Trick

    When asked to set a "Root password", leave both boxes completely blank and click Continue. By doing this, Debian will automatically grant your standard personal user sudo privileges, making it behave exactly like Ubuntu!

  5. User Details: Enter your full name, desired username, and a short, memorable password for your account.
  6. Timezone: Select your timezone based on the country you selected earlier.
  7. Partition Disks: Select "Guided - use entire disk". Select your target drive from the list, then choose "All files in one partition". Finally, select "Finish partitioning and write changes to disk" and click "Yes" to confirm.
  8. Package Manager: Select "No" for scanning extra media. Choose a Debian archive mirror country near you, select the default mirror (e.g., deb.debian.org), and leave the HTTP proxy blank.
  9. Software Selection: Check "Debian desktop environment", select your preferred desktop interface (GNOME is the default), and check "standard system utilities". Click Continue.
  10. GRUB Boot Loader: Select "Yes" to install the GRUB boot loader to your primary drive, and explicitly click your drive from the list (e.g., /dev/sda or /dev/nvme0n1).
  11. Completion: Once the installation finishes, click Continue to reboot, remove your USB drive, and boot into your new Debian workstation.
